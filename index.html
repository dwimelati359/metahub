Hubungkan ke Google Sheet

Paste URL Apps Script Web App kamu di bawah. Ini URL yang muncul setelah kamu deploy Apps Script dari Google Sheet.

  1. Buka Google Sheet → Extensions → Apps Script
  2. Paste kode backend → pilih fungsi SETUP_SHEET → klik Run
  3. Klik Deploy → New deployment → Web app
  4. Execute as: Me — Who has access: Anyone
  5. Copy URL yang muncul, paste di bawah

URL disimpan di browser kamu saja (localStorage). Tidak dikirim ke siapapun.
